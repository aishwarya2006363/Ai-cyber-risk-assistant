# AI Cyber Risk Assistant

## About the Project
AI Cyber Risk Assistant is a beginner-friendly cybersecurity risk assessment project developed using HTML, CSS and JavaScript.

It helps users calculate risk scores and view basic security control recommendations.

## Features
- Risk description input
- Likelihood and Impact assessment
- Automatic Risk Score calculation
- Low, Medium and High risk classification
- Rule-based security control recommendations
- Risk assessment history
- Risk dashboard
- Browser-based data storage using localStorage

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage

## Risk Calculation
Risk Score = Likelihood × Impact

Risk levels used in this learning project:
- 1–4: Low
- 5–14: Medium
- 15–25: High

These are illustrative thresholds, not a universal risk standard.

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server or a web browser.
4. Enter a risk description, likelihood and impact.
5. Click Analyze Risk.
